# Craftnime — Next-Generation Anime Streaming & Tracking Suite
**Part of the Crafted Co. Ecosystem**

Craftnime is the flagship anime streaming and tracking desktop and mobile client designed for Linux (Fedora Wayland/X11), Windows, and Android.

## ✨ Phase 1 Features
- 🎨 **Crafted Co. Brand Identity**: Custom Obsidian Dark Palette (`#1B1515`, `#241E1E`), Rust Accents (`#A9452D`), Electric Violet (`#6864F6`), and `Instrument Serif` + `Inter` typography.
- 🎬 **Netflix-Style Hero Billboard**: Autoplaying anime scene previews, dark vignette gradients, editorial titles, ratings, genres, and quick-play actions.
- 🚀 **Rich Anime Catalog & Carousels**: Live AniList GraphQL API integration + instant fallback cache for *Trending Now*, *Top 10 This Week* (ranked), *Popular This Season*, and *Continue Watching*.
- ⚡ **Interactive Episode Matrix & Quick View**: Episode grid with Sub/Dub indicators and instant watch triggers.
- 🎯 **MAL Auto-Sync Preview**: Integrated MyAnimeList profile status and auto-scrobble settings.

## 🚀 Quick Start
```bash
# Install dependencies
pnpm install

# Run dev server
pnpm dev

# Build production bundle
pnpm build
```
